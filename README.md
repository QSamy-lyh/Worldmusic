# Worldmusic · 世界音乐

> **一款不占你空间的鸿蒙本地音乐播放器。**
>
> 你有多少音乐躺在下载目录、网盘缓存、SD 卡里，却因为"要导入、要等、要占双倍空间"而懒得听？  
> Worldmusic 只做一件事：**让你的本地音乐，立刻能听**。

## 二、核心亮点

### ⚡ 秒级导入，不复制文件

选中音乐 → 立刻出现在列表里。100 首和 1 首的导入时间几乎一样，  
因为 App **从不搬运你的文件**，只记住它的位置。

> 实测：新增 2 首 38MB 的无损歌曲，**不到 1 秒**完成；同样的操作如果用"复制"方案需要 12 秒。

### 💾 零额外空间占用

曲库不产生任何副本。你看歌词、看封面用到的缓存都在系统缓存目录，随时可清、可自动回收。

### 📂 音乐始终在你自己手里

文件留在原处（下载目录、网盘缓存、U 盘、SD 卡都行），  
用系统文件管理器随时能看见、能改名、能移走、能备份 —— App 不会"劫持"你的音乐。

### 🎵 该有的播放体验一样不少

黑胶唱片式播放页、封面模糊背景、逐行滚动歌词、悬浮迷你播放条、  
系统播控中心与通知栏控制、后台播放、锁屏控制。

### 🎨 好看且能改

统一玻璃质感与圆角规范，跟随系统深色/浅色，主题色可自由更换；  
侧栏菜单项支持**长按拖动排序**，顺序按你的习惯来。

## 三、功能一览

**曲库管理**

- 添加音乐（支持多选，mp3 / flac / m4a / aac / wav / ogg）
- 扫描音乐文件夹（往专属目录里丢歌，一键收录）
- 自动去重 / 一键清理重复
- 长按改名、多选批量删除、收藏、播放记录

**播放**

- 顺序播放 / 单曲循环 / 随机播放
- 进度拖动、上一首/下一首、暂停继续
- 歌词自动匹配（支持同名 `.lrc` 与内嵌歌词）
- 断点续播：退出再进来，接着上次的位置

**系统集成**

- 播控中心卡片、通知栏控制、锁屏控制
- 后台播放，切到其他 App 也不断
- 平板/大屏适配，侧栏常驻与抽屉两种形态

## 四、三步开始用

1. **添加音乐** —— 侧栏点「添加音乐」，选中你的音乐文件（可多选，一次最多 100 个）
2. **开始播放** —— 点列表任意一首；底部迷你条会显示当前歌，点击进入播放页
3. **后续维护**（可选）
   - 音乐变多了：把新文件放进 `Download/Worldmusic`，点「扫描音乐」
   - 列表出现重复：点「清理重复歌曲」

> 首次使用会请求一次"读取所选文件"的授权，这是系统机制，授权后永久有效，重启不用再选。

## 五、关于隐私与安全

这一节值得单独说，因为它是本 App 的设计底线：

- ✅ **不上传任何数据**。没有账号、没有云端、没有网络请求，你的音乐库只存在这台设备上。
- ✅ **不复制、不移动、不修改**你的音乐文件。App 只读取。
- ✅ **不读通讯录、位置、相册**。只申请了「访问你所选文件」这一项存储权限。
- ✅ **删除的是列表记录，不是你的文件**。从曲库里移除一首歌，原文件仍然在原处。
- ✅ **覆盖安装、重启设备都不会丢曲库**（曲库信息存在 App 私有配置里，独立于音乐文件）。

## 六、常见问题

**Q：为什么文件管理器里看不到 App 的"音乐文件夹"？**  
因为以前版本会把音乐复制到 App 私有目录，那个目录按鸿蒙安全规范对用户和其他应用不可见。  
现在采用引用模式后，**音乐就在你原来的文件夹里**，文件管理器里随时可见。  
（App 自己的专属目录是可选的 `Download/Worldmusic`，同样对用户完全可见。）

**Q：列表里某首歌变灰了、显示"原文件已不存在"？**  
说明那首歌的源文件被删除、改名或移到了别的位置。把文件放回原处就会自动恢复；  
也可以重新「添加音乐」指一次新位置。App 不会因为找不到文件就删掉你的记录。

**Q：添加音乐后为什么没看到文件变多？**  
因为它没有复制。你选中的文件就是曲库的来源，位置不变、大小不变。

**Q：换手机 / 重装 App 后曲库还在吗？**  
曲库记录跟随 App 数据，卸载会清空（文件不会）。重装后重新「添加音乐」或「扫描音乐」即可恢复。

**Q：支持哪些格式？**  
mp3、flac、m4a、aac、wav、ogg；歌词支持同名 `.lrc` 与音频内嵌歌词。
